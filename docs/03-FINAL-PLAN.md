## 0. 왜 다시 A인가 — 그리고 무엇이 달라졌나

방향 A의 본질은 처음부터 옳았습니다: **작품-first 탐색은 아직 아무도 안 하는 시장의 빈자리**, 재고 없는 수익(AdSense+제휴), 1인이 감당 가능한 운영. 문제는 본질이 아니라 **입고 있던 옷**(AI스러운 색·가짜 이미지·과한 라운드)이었습니다. 그래서 이번 판은:

```
    [PROPOSAL-A의 뼈]                    [v2 하이브리드의 옷]
    작품→스팟 매칭 DB (심장)      +      순백 배경 · 쪽빛 인디고 · 세리프 헤드라인
    AdSense+제휴 수익 스택        +      TourAPI 실사진 파이프라인 (합법)
    챗봇·플래너 (체류장치)         +      5개 언어 · Leaflet 지도 · 위시리스트
    1인 운영 파일-CMS             +      매거진 골격 + 도구 페이지만 OTA 문법
```

## 1. 사이트의 성격 — "매거진이 도구를 품는다"

하이브리드의 배분 원칙은 딱 하나입니다:

> **읽는 페이지는 매거진처럼, 쓰는 페이지는 도구처럼.**

| 구역 | 성격 | 디자인 문법 |
|---|---|---|
| 홈 · /shows · /food · /beauty · /guide | 📖 **매거진 구역** — 감성·체류·AdSense | 대판 실사진, 세리프 헤드라인, 여백, 4px, 괘선 구분 |
| /spots · /map · /planner · /routes | 🛠 **도구 구역** — 탐색·전환·제휴 | 필터 칩, 리스트+지도 분할뷰, 저장♡, 8px, 정보 밀도 |
| /community · 필수 페이지 | 🤝 지원 구역 | 매거진 문법 따름 |

사용자 여정이 그대로 퍼널이 됩니다:
**정주행 끝(검색 유입) → 작품 허브에서 심장 뛰고(매거진) → 지도·플래너로 계획 세우고(도구) → 제휴 링크로 예약(수익) → Discord에서 자랑(재방문)**

## 2. 디자인 헌법 (전 페이지 불변 원칙)

1. **배경은 흰색이다.** #FFFFFF. 섹션 구분은 1px 괘선(#E5E5E5)과 여백으로만. 유일한 예외: 도구 구역의 옅은 밴드 #F7F8FA
2. **키칼라는 쪽빛 인디고 #1E3A6E 하나다.** 링크·버튼·활성 상태에만. 보조 셀라돈 #4A7A6D(태그), 경보성 레드 #C8102E('신작' 배지, 전체 5% 미만). ~~코랄~~ 금지
3. **라운드는 매거진 4px / 도구 8px.** 그 이상은 없다
4. **이모지는 UI에서 금지.** Lucide 라인 아이콘 1.5px로 통일 (콘텐츠 본문 인용 등 예외만)
5. **모든 이미지는 실사진 + 출처 캡션.** `<SourcedImage>` 컴포넌트가 강제 — 캡션 없는 이미지는 빌드에서 걸러냄
6. **헤드라인은 세리프**(영 Libre Caslon · 한 Noto Serif KR · 일/중은 Noto Serif 패밀리), 본문은 산세리프
7. 로고 리터치: `K·SPOT` 가운뎃점을 인디고로 — 색만 바꿔도 정체성 유지

## 3. 이미지·영상 파이프라인 (풍성함의 엔진)

| 단계 | 무엇 | 출처/근거 |
|---|---|---|
| 1 | `Spot`에 `tourApiContentId` 추가 → 수집 스크립트가 **실사진 2~4장·다국어 명칭·운영정보** 일괄 저장 | TourAPI 공공누리 1유형(출처표시 시 상업 가능) |
| 2 | 부족분은 포토코리아에서 수동 선별(1유형만) → `public/images/spots/` | 관광공사 공식 라이브러리 |
| 3 | 작품 허브에 공식 유튜브 임베드 1개(촬영지 홍보영상) | iframe 임베드 합법 |
| 4 | 제휴 승인 후 Klook 위젯(공식 크리에이티브) | 제휴 소재만 합법 |
| 원칙 | 드라마 스틸컷·타사 사이트 이미지 무단 사용 ❌ | AdSense·저작권 방어선 |

> 이 파이프라인의 진짜 의미: **"자료 풍성해 보이게"가 디자인 문제가 아니라 데이터 문제였고, 합법적으로 풀린다**는 것.

## 4. 페이지 청사진 (하이라이트만)

### 홈 — "오늘의 표지"
- 풀화이트 위 대판 실사진 히어로(계절별 교체) + 세리프 카피: *"You watched it. Now walk it."*
- 그 아래 3열: 🔎 작품으로 찾기 / 🗺 지도로 보기 / ✏️ 플래너 (아이콘은 Lucide)
- "지금 서울에서"(Visit Seoul API 이벤트 피드) — 사이트가 살아있다는 증거
- 트렌딩 작품 스트립 → 에디터 픽 루트 → 이번 주 식탁(식당) → K-뷰티 코너 → Discord 배너

### /shows/[slug] — 작품 허브 (매거진의 심장)
- 리드: 실사진(대표 촬영지) + 세리프 제목 + OTT/장르 메타 라인
- "Why fans visit" 인용문 스타일 박스 → 촬영지 리스트(장면 노트 = 이탤릭 캡션) → **미니 지도(이 작품의 스팟만 마커)** → 관련 루트/식당 → 공식 영상 임베드 → Klook 투어 위젯
- 하단: "이 작품 본 사람들이 함께 본 작품" (내부 회유)

### /spots + /map — 도구 구역의 얼굴
- **Airbnb식 분할뷰**: 좌 카드 리스트(필터: 작품·지역·유형) / 우 Leaflet 지도 실시간 연동
- 카드에 ♡ 저장, "N개 작품 등장" 배지
- 스팟 상세: 사진 갤러리 + 팩트박스(주소·시간·요금·가는법) + 등장 작품 타임라인 + "Google/Naver Map으로 열기"

### /planner — 검증된 로직, 새 옷
- 3스텝 위저드 유지(작품→일수→관심사), 결과는 **타임라인+지도 폴리라인 동시 표시**
- 결과를 URL로 인코딩 → **링크 하나로 저장·공유**(Wanderlog 차용) → Discord 공유 CTA
- 이메일 PDF(A안 계승)는 P4에서

### /guide · /food · /beauty — AdSense 삼형제
- 가이드 12편: 세리프 제목 + 드롭캡 첫 문단 + 섹션 사이 광고 슬롯(기존 구조 재사용)
- 식당: CatchTable 예약법 스텝박스 유지 + 실사진
- 뷰티: "한국에서 산다(올리브영 13%) / 집에서 시킨다(StyleKorean 12%·YesStyle 10%)" 이중 동선 + 관광공사 쇼핑 가이드 딥링크

### 챗봇 — "Ask the Editor"
- 플로팅 원형 폐기 → **하단 고정 슬림 바**(검색창 모양, 인디고 테두리): "이 사이트의 에디터에게 물어보세요"
- 클릭 시 시트 확장, 추천 질문 3개(언어별 현지화), 답변에 근거 페이지 카드 첨부
- 질문 언어로 답변(5개 언어), 기존 폴백 로직 유지하되 말투를 에디터 톤으로 재작성

## 5. 다국어 — 5개 언어, 3층 공급

- **next-intl**: `/en /ko /ja /zh /es` + 헤더 지구본 스위처 + hreflang
- 1층 UI 문자열: 5개 언어 즉시 (수백 개 키, 1회 작업)
- 2층 스팟 팩트: **TourAPI 다국어 서비스가 공급**(영/일/중/서 공식 번역 — 번역비 0)
- 3층 에디토리얼: 영어 원문 → AI 초벌 + "기계번역" 라벨 → 트래픽 상위부터 사람 검수
- SEO 효과: 일본어·스페인어권 K-드라마 검색은 경쟁 무주공산 — 다국어가 곧 트래픽 전략

## 9. 이 기획이 재밌는 이유 (셀프 세일즈 3줄)

1. 경쟁사는 "서울 투어 팝니다"라고 말하지만, 우리는 **"눈물의 여왕 마지막 화 그 정원, 실제로 있어요"**라고 말합니다 — 클릭하는 쪽은 정해져 있습니다.
2. 관광공사가 세금으로 찍은 최고급 사진을 **합법적으로, 출처 한 줄로** 쓰는 사이트 — 개인 블로그는 몰라서 못 하고, 대형 OTA는 작품 축이 없어서 못 합니다.
3. 팬의 여정 전체(설렘→계획→예약→자랑)가 한 사이트 안에서 끝나는데, 운영은 **일주일에 TS 파일 두 번 고치는 것**입니다.
