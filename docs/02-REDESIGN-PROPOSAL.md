## 1. 현재 버전의 문제점 (솔직한 진단)

| # | 문제 | 왜 "AI 티"가 나는가 |
|---|---|---|
| 1 | **키칼라가 코랄/테라코타(#E8442E)** | 지적하신 대로 Claude 브랜드 계열 색. 여행 산업의 신뢰 색상(블루/네이비/그린 계열)과 동떨어짐. Booking·Trip.com·아고다가 파란색을 쓰는 이유는 '신뢰·안전'이 여행 구매의 1순위 감정이기 때문 |
| 2 | **실사진 0장 — 그라디언트+이모지 카드** | 여행 사이트의 상품은 '장소의 실물'인데 전부 추상 그래픽 → 자료가 빈약해 보이고 전형적인 'AI 생성 사이트' 인상. 저작권 회피를 디자인으로 때운 결과 |
| 3 | **다크 네이비 히어로 + 크림 배경** | 흰색 배경 요청과 배치. 어두운 히어로는 포트폴리오/스타트업 랜딩 문법이지 여행 미디어 문법이 아님 |
| 4 | **라운드 24px(rounded-3xl) 남발** | 장난감 같은 인상. 실제 여행 사이트들은 4~12px 사이 (Booking 4px, Airbnb 8~12px, Klook 8px) |
| 5 | **이모지 과다 (🔥⭐✨🍜)** | UI 아이콘을 이모지로 대체한 것 자체가 AI 산출물의 전형적 특징 |
| 6 | **챗봇 UX 미완성** | 뜬금없는 플로팅 원형 버튼, 폴백 답변이 기계적("Here is what matches best…"), 사이트 디자인과 이질적 |
| 7 | **영어 단일 언어** | 타깃(해외 다국적 팬)과 불일치. 언어 전환 없음 |
| 8 | **지도가 스팟 상세의 정적 iframe 1개뿐** | 여행 계획 도구로서의 핵심 기능(전체 지도에서 탐색, 루트 시각화) 부재 |
| 9 | **외부 연동이 '검색 링크' 수준** | Klook 검색 URL 정도. 관광공사·K뷰티 종합몰·공식 영상 등 생태계 연동 없음 |

## 2. 이미지/영상 — 법적으로 안전한 조달 전략 (이번 개편의 핵심)

### 2.1 결론부터: 무엇이 되고 안 되는가

| 출처 | 사용 가능 여부 | 조건 |
|---|---|---|
| **TourAPI 4.0 이미지** (한국관광공사) | ✅ **가능 (핵심 공급원)** | 공공누리 제1유형 = 출처표시하면 상업적 이용 가능. 단, 기업 CI/BI 사용·명예훼손적 사용 금지. API 응답의 이미지 URL + "ⓒ한국관광공사" 캡션 자동화 |
| **포토코리아** (phoko.visitkorea.or.kr) | ✅ 가능 (사진별 확인) | 관광공사 공식 사진 라이브러리, 회원가입 후 무료 다운로드. **사진마다 라이선스가 달라** 공공누리 1유형 표시분만 선별 사용 + 출처표시 |
| **Visit Seoul API 이미지** | ⚠️ 조건부 | API 키 발급 + 포털 이용약관 확인 후 사용 (서울관광재단 콘텐츠 3,700건+, 7개 언어). 약관상 출처표시 조건 확인 필요 — 키 신청 시 명시됨 |
| **공식 유튜브 임베드** | ✅ 가능 | KTO 'Imagine your Korea' 채널, Visit Seoul TV 등 공식 채널 영상의 **iframe 임베드**는 유튜브 약관상 합법. 다운로드/재편집은 불가 |
| **Klook/Trazy 제휴 크리에이티브** | ✅ 제휴 가입 후 | Klook 어필리에이트는 공식 배너·위젯·검색박스를 제공 — 이것만 합법. 커미션 2~20% 덤 |
| **Klook/Trazy/Creatrip 사이트 이미지 무단 복사** | ❌ **불가** | 상업 사이트의 사진은 저작권 보호 대상. 제휴 프로그램이 제공하는 소재 외에는 사용하면 안 됨 |
| **드라마 스틸컷/포스터** | ❌ 불가 (기존 방침 유지) | AdSense 탈락 + 법적 리스크. 장소 실사진으로 작품을 표현 |

### 2.2 실행 설계 (코드 반영 방식)

1. `Spot` 타입에 `tourApiContentId` 필드 추가 → 스크립트가 TourAPI에서 **이미지 URL·다국어 명칭·상세정보를 한 번에 수집**해 데이터 파일에 저장 (런타임 API 의존 없음 = 속도/안정)
2. `<SourcedImage>` 공용 컴포넌트: 이미지 + 출처 캡션("ⓒ Korea Tourism Organization – TourAPI") 자동 표기 → 라이선스 준수가 구조적으로 강제됨
3. 작품 상세 페이지에 공식 유튜브 임베드 슬롯 (예: KTO 촬영지 홍보영상, Visit Seoul 지역 영상)
4. 제휴 승인 후: Klook 위젯을 스팟/루트 페이지 사이드에 배치

### 2.3 필요한 사전 작업 (운영자, 무료)

- [ ] data.go.kr에서 TourAPI 활용신청 (국문+영문+일문+중문간체+스페인어 서비스, 즉시 승인)
- [ ] api.visitseoul.net 회원가입 + 키 발급
- [ ] 포토코리아 회원가입
- [ ] Klook 어필리에이트 가입 (affiliate.klook.com)

## 3. 메인으로 반영할 출처 3가지 + 응용법 ⭐

### ① 한국관광공사 TourAPI 4.0 (+ 포토코리아)
**무엇**: 관광지 26만 건 데이터·이미지·운영시간·교통, 영/일/중(간·번)/독/불/서/러 다국어 서비스, 공공누리 1유형.
**응용**:
- 스팟 36곳 전체에 실사진 2~4장 갤러리 + 공식 상세정보(주소·시간·요금) 자동 보강 → **"자료 풍성함"을 하루에 해결하는 유일한 합법 경로**
- 다국어 명칭·설명을 그대로 받아 5개 언어 콘텐츠의 골격으로 사용 (번역 비용 0)
- 주변 관광지 API로 스팟 상세에 "근처 가볼 곳" 자동 섹션

### ② Visit Seoul API (서울관광재단)
**무엇**: 서울 명소·맛집·축제·이벤트 3,700건+, 한/영/일/중간/중번/러/말레이어.
**응용**:
- 서울 스팟(전체의 60%)의 이미지·설명 이중 보강
- **"지금 서울에서" 섹션**: 진행 중인 축제/이벤트/팝업을 API로 받아 홈에 노출 → 사이트가 '살아있는' 느낌 (재방문 이유 = 트래픽)
- 드라마 팝업스토어·전시 정보를 작품 페이지와 연결 (예: HiKR Ground K-드라마 체험관)

### ③ Klook 어필리에이트 프로그램
**무엇**: 공식 배너/위젯/검색박스 제공, 투어 6.5%·액티비티 5%·**eSIM 20%** 커미션, 30일 쿠키.
**응용**:
- 스팟/루트 페이지에 해당 지역 투어 위젯 (합법 이미지 + 수익 동시 해결)
- **eSIM 20%가 숨은 보석**: 이미 있는 'SIM/eSIM 가이드' 아티클이 최적의 전환 지면 — 콘텐츠→수익 직결 1호 후보
- 가이드 투어가 필요한 원거리 촬영지(강원 주문진 등)에 "이동이 어렵다면 투어로" 박스

**보조 출처**: 올리브영 글로벌(최대 13%) + **StyleKorean(12%, PayPal 정산)** + **YesStyle(10%, 52개국 배송)** → K뷰티 페이지에서 "한국에서 사기(올리브영) / 집에서 주문(StyleKorean·YesStyle)" 이중 동선 · KTO 공식 유튜브(영상) · visitkorea.or.kr 딥링크(스팟마다 공식 가이드 링크)

## 4. 재설계 방향 2가지

### 방향 1 — "The K Edit" (에디토리얼 매거진형)

**벤치마킹**: Condé Nast Traveler, Time Out Seoul, Monocle Travel Guide, 매거진 B

| 요소 | 스펙 |
|---|---|
| 배경 | 순백 #FFFFFF, 섹션 구분은 흰색+1px 괘선(#E5E5E5)으로만 |
| 잉크 | #111111 (순수 블랙에 가까운 잉크) |
| **키칼라** | **딥 인디고 #1E3A6E (쪽빛)** 단 하나 — 링크·버튼·강조에만 절제 사용. 보조로 셀라돈 그린 #4A7A6D 태그 정도 |
| 타이포 | 헤드라인 세리프(영문 Libre Caslon/국문 Noto Serif KR) + 본문 산세리프 → 매거진 인상의 80%는 세리프 헤드라인에서 나옴 |
| 라운드 | 4px (이미지·카드), 버튼 4px — 요청하신 1/3 수준 |
| 레이아웃 | 대판 사진 리드 + 2단 그리드, 넉넉한 여백, 사진 캡션 문화(출처 표기가 오히려 매거진답게 보임) |
| 이모지 | 전면 제거, 1.5px 라인 아이콘(Lucide)으로 교체 |
| 챗봇 | 플로팅 원형 제거 → 하단 고정 **"Ask the Editor" 슬림 바** (검색창처럼 생긴 입력줄, 클릭 시 시트 확장) |
| 어울리는 것 | 장문 가이드·사진·감성 스토리텔링, AdSense 프리미엄 지면 단가 |
| 리스크 | '도구' 느낌 약함 — 플래너·지도가 부록처럼 보일 수 있음 |

### 방향 2 — "K-Route Finder" (OTA 프로덕트형)

**벤치마킹**: Booking.com(정보 밀도·신뢰 블루), Airbnb(지도 분할 뷰), Klook(카테고리 칩·상품 카드), Wanderlog(일정 타임라인)

| 요소 | 스펙 |
|---|---|
| 배경 | 순백 #FFFFFF + 섹션 밴드 #F7F8FA (그레이 50) |
| **키칼라** | **트러스트 블루 #0B5BD3** (Booking·Trip.com 계열의 신뢰 색) + 텍스트 네이비 #13294B. 포인트 최소량으로 태극 레드 #C8102E (배지 '인기'·'신작' 정도, 전체의 5% 미만) |
| 타이포 | 전면 산세리프(Inter/Pretendard), 굵기 대비로 위계 표현 |
| 라운드 | 8px (카드), 6px (버튼/입력) — 요청하신 1/3 수준 |
| 레이아웃 | 상단 검색바(작품명 입력) 중심 히어로, 필터 칩 줄, **리스트+지도 분할 뷰**(Airbnb식: 좌측 스팟 카드·우측 인터랙티브 맵), 저장(♡)·비교 기능 |
| 이모지 | 제거, 기능 아이콘 체계 |
| 챗봇 | 우하단 → **우측 슬라이드 패널 "Trip Assistant"**: 추천 질문 카드 3개 먼저 노출, 답변에 스팟 카드 첨부 |
| 어울리는 것 | 플래너·지도·제휴 전환(위젯이 자연스럽게 녹음), B단계 커머스 확장 시 무리 없음 |
| 리스크 | 콘텐츠 감성 약화 — 가이드 아티클이 '도움말'처럼 보일 수 있음 |

**추천**: 목표가 "AdSense+제휴 수익의 콘텐츠 미디어"(방향 A 유지)이므로 **방향 1을 기본 골격**으로 하되, /spots·/planner·/map에만 방향 2의 분할 뷰·필터 문법을 부분 채용하는 하이브리드가 최적. 다만 두 안 모두 완결 구조로 설계했으므로 선택만 하시면 됩니다.

## 5. 공통 반영 기능 (어느 방향이든 포함)

### 5.1 다국어 5개 언어 (EN/中文/日本語/Español/한국어)
- next-intl 도입, URL 프리픽스(`/en /zh /ja /es /ko`), 헤더 우측 언어 스위처(지구본 아이콘)
- 번역 3층 전략: ① UI 문자열 = 즉시 5개 언어 ② 스팟 명칭·주소·기본정보 = TourAPI 다국어 서비스에서 공급 ③ 에디토리얼(가이드 12편 등) = 영어 원문 → AI 초벌 번역 + 표시("기계번역 안내") → 트래픽 상위 문서부터 검수. hreflang 태그로 언어별 SEO 색인

### 5.2 인터랙티브 지도
- **Leaflet + OpenStreetMap** (API 키·비용 불필요, 상업 사용 가능) 채택
- `/map` 신설: 전체 스팟 마커 + 작품/지역 필터 + 클릭 시 카드 팝업
- 루트 상세: 일자별 경유지 번호 마커 + 폴리라인
- 스팟 상세: 현 정적 iframe → 미니 인터랙티브 맵 + "Google Maps/Naver Map으로 열기" 버튼(현지 내비 연동)

### 5.3 해외 여행 사이트에서 차용할 사용자 기능 (선별 4개)
| 기능 | 출처 벤치마킹 | 구현 |
|---|---|---|
| 위시리스트 ♡ 저장 | Airbnb/Klook | localStorage 기반(로그인 불필요), 헤더에 저장 카운트 |
| 플랜 저장·재열람 | Wanderlog | 플래너 결과를 URL 파라미터로 인코딩 → 링크만으로 공유/재열람 |
| "지금 서울" 이벤트 | Time Out | Visit Seoul API 이벤트 피드 |
| 지역 날씨 칩 | Booking | 루트/스팟에 계절 안내(정적 데이터로 시작, 추후 날씨 API) |

### 5.4 챗봇 품질
- 페르소나 재작성(기계적 목록 → 여행 에디터 말투), 답변에 근거 페이지 카드 첨부, 언어 자동 감지(질문 언어로 답변), 추천 질문 현지화

## 6. 마이그레이션 계획 (기존 자산 재활용)

**유지**: 데이터 14작품/36스팟/8루트/12식당/가이드 12편(콘텐츠 가치 그대로), 라우트 구조, lib/data.ts 접근 계층, AdSense 파일들

**신규**: i18n 레이어, TourAPI 수집 스크립트, /map, 위시리스트, 이벤트 피드, 제휴 위젯 슬롯

순서: ① 디자인 토큰+리스킨(흰 배경·새 키칼라·4~8px) ② TourAPI 이미지 파이프라인 ③ i18n ④ 지도 ⑤ 신기능 — ①②만 끝나도 "AI 티" 문제의 8할이 해결됩니다.
